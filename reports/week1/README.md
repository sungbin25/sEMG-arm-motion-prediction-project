## 데이터 이해와 클래스 설계

- 8명 × 8조건 = 연속 기록 64개, 시행 마커 1,920개.
- 1,000 Hz, 5채널(ECR, ED, FDS, Biceps, Triceps).
- 30도·60도 × 주먹 쥐기·손 펴기·회내·회외 = 8클래스.
- `pro`는 회내, `extor`는 회외이다. 클래스당 시행 마커는 240개다.
- CSV 한 파일에 시행 30개가 들어 있다. 마커 상승점을 기준으로 5초 관찰 구간을 추출했다.
- 공개 데이터는 이미 필터링되어 있어 1주차에는 중복 필터링하지 않았다.
- 신호 확인, RMS 비교, 클래스 설계와 데이터 품질 검사를 수행했다. 모델 학습 및 성능 평가는 수행하지 않았다.

마커가 시행 시작인지 실제 동작 시작인지는 확인되지 않았다. 5초 전체 RMS는 휴식을 포함하며 실제 동작 구간만의 근활성으로 해석하지 않는다.
